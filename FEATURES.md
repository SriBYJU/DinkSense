## Honest limitations
- single-phone pose grading is not laboratory biomechanics
- paddle-face angle, paddle speed, ball trajectory, spin, and bounce location are not directly measured
- automatic DUPR verification needs approved access
- shared accounts, crowds, leaderboards, and cloud sync need a backend
- automatic tournament and retailer feeds need external data agreements

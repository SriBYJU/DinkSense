# Google AdSense Setup

DinkSense includes labeled ad spaces only on lower-priority screens. No ad placement is inserted into match logging, AI coach chat, live form grading, health recommendations, or other high-focus actions.

1. Publish DinkSense on your final HTTPS domain or GitHub Pages URL.
2. Apply for and receive Google AdSense approval.
3. Open `adsense-config.js`.
4. Set `enabled: true`.
5. Replace the publisher client and each desired responsive ad slot with the exact values supplied in AdSense.
6. Upload the revised file and hard-refresh the site.

Do not use placeholder IDs as real ad code. Follow the latest AdSense program and placement policies.
